# 実証実験

このディレクトリはWork Memory / Work Traceの初期実証実験を管理する。

## 目的

Work TraceをWork Itemへ自動紐付けする仕組みの実用性を検証する。

## 実験対象

10 Work Items、9パターン。

- 電話 × 2
- メール × 1
- 文書閲覧 × 1
- Web調査 × 1
- 他者依頼 × 1
- 割り込み × 1
- 並行案件 × 1
- 完了フォロー × 1
- 複数日 × 1

## 評価

- 自動紐付け成功：7/10以上 = GO、5/10以下 = STOP
- 誤紐付け：1件以下 = GO、3件以上 = STOP
- 平均訂正時間：10秒以下 = GO、20秒以上 = STOP
- 未分類率：30%以下 = GO、50%以上 = STOP

中間値は20件まで拡張する。

結果を見て基準を変更しない。
