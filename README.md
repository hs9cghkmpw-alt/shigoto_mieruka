# 仕事みえる化 / Work Memory / Work Trace

## 目的

実際の仕事で発生するWork Traceを記録・分析し、**就労能力を可視化する**ための基盤。

単純な工数管理や従業員監視ではなく、本人がどのような仕事・環境・支援条件で能力を発揮できるかを、実データから明らかにすることを目的とする。

## 設計思想

> 人の能力を単一スコアで評価するのではなく、人・仕事・環境・支援の適合関係をデータから発見する。

## 現在地

仕様の机上レビューは一旦凍結し、**実証実験を優先する段階**。

最大の技術的ゲートはWork TraceとWork Itemの自動紐付け。

## 次の開発対象

1. 実験ログ雛形
2. Work Item管理
3. Work Trace入力
4. 暫定自動紐付け
5. 訂正UI
6. 未分類トレイ
7. 実験結果集計

## 原則

- FACT / ANALYSIS / KNOWLEDGEを混同しない
- observed / reportedを保持する
- AIの推測を事実として保存しない
- 誤紐付けより未分類を優先する
- 記録負担を実測する
- 外部AIはデフォルトOFF
- 人事評価を単一スコアで自動化しない
- 実験結果を見てGO/STOP基準を変更しない
