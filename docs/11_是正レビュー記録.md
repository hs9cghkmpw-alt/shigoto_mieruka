# 是正レビュー記録

## 目的

2026-09-09の厳格レビューで指摘された「実験用コードとしては成立しているが、実運用基盤として誤解を招く箇所」を是正し、実装状態と主張を一致させる。

## 是正した項目

### 1. Association Engine

単なるスコア計算関数だけでなく、観測済みシグナルから候補を生成し、暫定紐付け結果と候補一覧を返す `association.engine` を追加した。

### 2. 実験結果の自己申告を排除

CSVの `result` を集計結果として信用せず、`predicted_work_item_id`、`expected_work_item_id`、`confidence` からGO/GRAY/STOPを再計算する。

入力された `result` と再計算結果が一致しない場合はログを拒否する。

### 3. Assignment状態遷移

暫定紐付け、本人確認、訂正を明示的な処理として分離した。

訂正では、変更前Work Item、変更後Work Item、訂正者、理由、時刻を `AssignmentCorrection` として保持する。

### 4. 未分類への復帰

訂正先を `None` にでき、判断不能なTraceを再びUNASSIGNEDとして扱えるようにした。

### 5. 古い生成ログの除去

旧仕様の `experiment/experiment_log.csv` は新しい実験CSV仕様と矛盾するため、リポジトリから削除した。CIが生成する実験ログだけを成果物とする。

### 6. READMEの状態表示

「次の開発対象」として既に実装済みの機能を並べる状態を修正し、Phase 1で実装済みの範囲と未実装の境界を明記した。

## まだ意図的に実装していないもの

- メール・チャット・ファイル等の実データコネクタ
- 常時監視
- 高度な意味理解AI
- FACT → ANALYSIS → KNOWLEDGEの長期パイプライン
- Capability Profileの統計モデル
- 訂正UI
- 未分類トレイUI

これらは「残作業を隠す」のではなく、Phase 1の安全性と検証可能性を優先して明示的に境界化する。

## 判定基準

この文書以降、「完成」という表現は **Phase 1の実験可能な基盤としての実装完了** に限定する。

実運用データによる有効性検証を完了したとは表現しない。
